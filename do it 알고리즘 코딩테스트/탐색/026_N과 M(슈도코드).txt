N, M(1~N까지 자연수를 선택하여 길이 M인 수열 모두 구하기)
V(숫자 사용 여부 저장 배열)
S(수열 정보 저장 배열)
백트래킹 실행(매개변수: 수열의 길이)

// 백트래킹 상세 구현
backtracking(수열 길이) {
    if(길이가 M인 수열이 만들어진 경우)
        수열 정보 출력 및 함수 반환
    for(1~N까지 자연수 탐색) {
        if(아직 수열에 포함되지 않은 수인 경우) {
            V 배열에 수 사용 표시
            수열에 수 추가
            수열 길이는 1 증가시키고 backtracking 함수 재귀 호출
            V 배열에 수 사용 표시 제거
        }
    }

}

// 백트래킹 설명 보완
backtracking(현재 길이):

    현재 길이가 M이면
        완성된 수열을 출력한다.
        현재 함수를 종료한다.

    1부터 N까지 모든 숫자를 확인한다.

        현재 숫자를 아직 사용하지 않았다면
            현재 숫자를 사용 중으로 표시한다.
            현재 위치에 숫자를 저장한다.

            다음 위치의 숫자를 선택하기 위해
            수열 길이를 1 증가시켜 재귀 호출한다.

            재귀 탐색이 끝나 현재 위치로 돌아오면
            현재 숫자의 선택을 취소한다.
